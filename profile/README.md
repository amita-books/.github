## 이렇게 만듭니다

- **모든 코드는 실제로 돌아갑니다.** 책에 실린 코드는 저장소의 예제 프로젝트에 그대로 있고, 빌드와 테스트로 검증합니다. 확인하지 못한 내용은 본문에 그렇다고 적습니다.
- **책 한 권으로 충분하게.** 인터넷 없이 읽어도 되도록 필요한 설정, 오류 대처법, 용어를 책 안에 담습니다.
- **인쇄해서 읽을 수 있게.** A4 흑백 PDF로 냅니다. 코드에는 실제 파일 경로와 줄 번호가 붙습니다.
- **원고도 소스입니다.** 원고(Markdown), PDF 빌드 도구, 예제, 환경 구성 문서를 모두 공개합니다.

## 저장소 둘러보기

책마다 저장소가 하나씩 있고, 이름은 `book-주제`입니다. 구성은 같습니다.

| 폴더 | 내용 |
|------|------|
| `book/` | 원고와 PDF 빌드 도구 |
| `examples/` | 책에 실린 모든 예제 프로젝트 |
| `docs/` | 환경과 버전, 예제 실행법, 오프라인 반입, 책 빌드, 결정 기록 |

완성된 PDF는 각 저장소의 **Releases**에 있습니다.

새 책은 [book-template](https://github.com/amita-books/book-template)에서 시작합니다. 빌드 도구, 원고와 부록의 틀, 작업 지침이 들어 있습니다.
